# crypto-tail-scout OAuth disclosure

This public repository contains only the Google OAuth homepage and privacy
policy for the owner's personal `crypto-tail-scout-rclone` backup client.

It contains no crypto-tail-scout source code, research data, credentials,
tokens, operational configuration, or project authority documents.

The OAuth client:

- is used by one owner;
- transfers versioned backup files between the owner's computer and private
  Google Drive through rclone;
- requests only the non-sensitive Google Drive `drive.file` scope;
- has no public service or sign-up flow;
- does not sell, share, or use Google user data for unrelated purposes.

After GitHub Pages is enabled, the public disclosures are available at:

- Homepage: <https://baumierpierre769-stack.github.io/crypto-tail-scout-oauth/>
- Privacy policy: <https://baumierpierre769-stack.github.io/crypto-tail-scout-oauth/privacy.html>

The private `crypto-tail-scout` repository remains the only project codebase.
This repository is not a project rulebook, continuity handoff, data store, or
normative source.
