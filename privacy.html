Privacy Policy

Application: crypto-tail-scout-rclone

Effective date: September 7, 2026

Purpose and users

crypto-tail-scout-rclone is a personal OAuth client used by one owner. Its sole purpose is to back up and restore the owner's crypto-tail-scout research datasets between the owner's computer and the owner's private Google Drive through rclone. It is not offered as a service to third parties.

Google data accessed

The client requests only https://www.googleapis.com/auth/drive.file. This scope allows it to create, read, update, and delete only Google Drive files and folders it creates or that are explicitly opened with it. It does not request access to unrelated Drive files, Gmail, Google Photos, contacts, profile data, or other Google services.

The planned backup workflow uses versioned copy operations and does not automatically synchronize remote deletions. Rclone retains the technical ability to delete files created by this client when the owner explicitly requests such an operation.

Data flow and storage

Backup files originate on the owner's computer and travel directly between rclone on that computer and Google Drive through the official Google Drive API. There is no independent application server or database. OAuth credentials and tokens are stored only in rclone's local configuration and are not uploaded to this website or its public repository.

This static disclosure website does not receive Google user data. It is hosted by GitHub Pages, so ordinary website request information may be processed by GitHub under the GitHub General Privacy Statement .

Sharing and secondary use

Google user data is not sold, transferred, used for advertising, or disclosed to third parties. Backup files remain private in the owner's Drive unless the owner independently changes their Drive sharing settings. Google user data is not used for surveillance, credit, advertising, or any purpose unrelated to personal backup and restoration.

Retention, deletion, and revocation

The owner controls retention and may delete backup files through Google Drive or rclone. The owner may revoke the client's access at any time from the Google Account's third-party access settings and may remove the local rclone configuration and tokens.

Security

The client uses Google's OAuth 2.0 authorization flow and HTTPS through rclone. Credentials are kept out of the public repository and project datasets. Access is limited to the minimum drive.file scope.

Changes

This policy will be updated before the client requests broader Google access or uses Google user data for a new purpose. Any such change would require renewed informed consent.

Contact

Questions about this personal client may be submitted through the repository issue tracker .
